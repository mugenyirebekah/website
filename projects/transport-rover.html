Transport Rover

A line-following rover to move things around an industrial area

Role

Design & build

Stack

IR sensors, embedded C++, mobile app control

Tags

Robotics

A prototype industrial rover built at the Uganda Industrial Research Institute (UIRI) to automate inter-lab material transport, following a defined line path between laboratory stations. Uses IR sensors for reliable path detection and includes mobile-app control so operators can command it remotely.
